THOUGHT / MEMORY / AUTHORITY

Huginn and Muninn. Two ways to stay connected.

HUGINN · DISCORD / PORTABLE

Reach outward. Bring back a plan.

Huginn is the mobile-facing Raven: Discord on your phone, with the model and agent host running elsewhere. The DeepSeek API path offers economical inference and an independently hosted fallback to the cockpit. Availability still depends on the channel, host, network and provider.

Cognitive function: capture an objective, gather supplied context, clarify constraints and request deeper planning or review through Warden Hand. Trinity’s structured response becomes guidance for the next Raven turn.

Agentic capability: OpenClaw can execute enabled tools and access configured local paths or cloud connectors on its host. Direct DeepSeek API mode is chat only; the provider itself does not provide file access.

Authority: explicitly scoped tool permissions. No inherited Cortex session, unrestricted backend access or automatic memory promotion. A remote Cortex read bridge remains a proposed integration.

MUNINN · YGGDRASIL / COCKPIT

Recall context. Inspect the system.

Muninn is the memory-facing Raven in the Yggdrasil UI. Its privileged Cortex read role places retained evidence, working context and system state close to the operator.

Cognitive function: maintain continuity, retrieve relevant context, connect present questions to the knowledge graph, and help the operator inspect what the engine knows and where uncertainty remains.

Inference: local-host models or configured APIs can support the cockpit. Role and authority follow backend policy, not the price or location of the model.

Authority: permitted Cortex reads within the cockpit boundary. Tool execution, filesystem writes, governed knowledge writes and process control are separate capabilities; a read role does not grant them.

These names describe roles, not two fixed model products. The local and Discord lanes below illustrate deployment choices. Neither a role name nor a returned plan grants permission.

CORTEX / READ SURFACES

Expose useful context. Keep authority explicit.

The inspected Yggdrasil backend defines these read endpoints. Their presence verifies a backend surface, not a completed Huginn connector or a public service.

Memory & continuity

GET /memory/status
GET /memory/stm
GET /memory/working-ledger

Memory summaries, recent context and the working ledger. Filter task-relevant fields before forwarding context to any external model.

Graph & topology

GET /ltkg/stats
GET /ltkg/snapshot
GET /ltkg/neighbourhood

Graph statistics and bounded views of retained relationships. Read access should be scoped to the caller and the question.

Remote bridge · proposed

An authenticated, read-only backend adapter could return an allowlisted context envelope to Huginn: evidence references, provenance, freshness and explicit omissions.

Deployment work: authorize the caller, bound queries and response size, redact private fields and record access. No raw backend credentials in Discord or browser exports.

This website calls none of these endpoints and changes no backend exposure. Remote read access requires implementation and authorization. Memory mutation and agent execution remain separate paths.

    THE IDEA BEHIND THE SETUP
    Put deeper thought where it helps.
    A smaller or economical worker model does not have to solve every planning problem alone. Trinity can supply a broader plan, compare perspectives, and return a structured result the worker can follow.
    The potential benefit comes from the handoff: a clear objective, grounded evidence, explicit constraints and reviewable steps. Whether it improves task outcomes needs a matched evaluation with recorded model versions, tool access and budgets.
